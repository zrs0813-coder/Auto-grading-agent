# MIA 5100 Auto-Grading Agent

Grades group project reports against a rubric derived from the Project Instruction
document, using an LLM served by the **Geotab GenAI Gateway**.

## Workflow

1. **Read the instructions.** The Project Instruction PDF is parsed once per run.
2. **Build track rubrics.** A 30-point rubric is generated for each track and
   cached in `rubrics.json`, so every group in a track is graded against an
   *identical* rubric. Delete the file or pass `--refresh-rubrics` to rebuild.
   - Track 1 — Hands-On AI System Development Project (Build & Evaluate)
   - Track 2 — AI System Design Project (Analyze & Design)
3. **Per group:** load the report (PDF or DOCX), classify it into Track 1 or 2,
   then grade it criterion by criterion against that track's rubric.
4. **Output** a CSV, an Excel workbook, a readable Markdown report, and raw JSON.

Each criterion gets a **score**, **evidence** from the report, a **deduction
reason** (empty when full credit), and brief **feedback**. The group total is
computed from the criterion scores in Python — never taken from the model.

## Grading policy

Grading is deliberately lenient; full credit is the default outcome. No deductions
for grammar, style, organization, page count, or reasonable alternative approaches.
Deductions require a clear, substantive rubric violation backed by specific
evidence from the submission.

## IEEE format criterion

Every rubric carries a fixed **IEEE Conference Format & Structure** criterion worth
**2 of the 30 points**. It is defined in code (`IEEE_CRITERION`), not generated by
the model, so it is always present at exactly that weight; the model generates only
the remaining 28 points of content criteria, and any format criterion it invents
anyway is dropped to prevent double-counting.

It is graded leniently and **on structure only** — abstract, index terms, numbered
sections, figure/table captions, numbered reference list. Text extracted from a PDF
or DOCX carries no column layout, font, or margin information, so the model is
explicitly told not to judge what it cannot see. Full credit unless the report
plainly disregards the template altogether. No other criterion may deduct for
formatting.

## Setup

```bash
pip install -r requirements.txt
```

Put your gateway credentials in `.env` (gitignored):

```
GENAI_API_KEY=<your token>
GENAI_BASE_URL=https://genai-us.geotab.com/api/v2   # region: us | eu | ca
GENAI_MODEL=claude-opus-5
```

Token: https://dpmc.geotab.com/gen-ai/ (or the `token` field of `~/genai.json`).

## Expected folder layout

```
<root folder>/
  594505-... Group 1 .../   MIA5100 Project Report_Group_1.pdf
  594506-... Group 2 .../   Report.docx
  ...                       (12 group folders, one report each)
MIA5100 - Project - Instructions.pdf
```

Group folders are matched on `Group <n>` in the folder name and sorted
numerically. Within a folder the report is found recursively; if several
PDF/DOCX files are present, one whose name contains "report" or "final" wins.

## Run

```bash
python grading_script.py                       # all groups
python grading_script.py --limit 2             # cheap smoke test
python grading_script.py --groups 6,12         # only specific group numbers
python grading_script.py --refresh-rubrics     # rebuild rubrics
python grading_script.py --root "<folder>" --outdir results
python grading_script.py --model claude-opus-5
```

## Output

| File | Contents |
|---|---|
| `grading_summary_<ts>.csv` | One row per group: track, total, percentage |
| `grading_detail_<ts>.csv` | One row per criterion: score, evidence, deduction, feedback |
| `grading_results_<ts>.xlsx` | Same data as Summary + Criterion Detail sheets |
| `grading_report_<ts>.md` | Readable report: gradebook, both rubrics, per-group breakdown |
| `grading_raw_<ts>.json` | Full structured results |

## Notes

- Max score is **30** points per report. The instruction document states 25 for
  the report deliverable; 30 is used per course-staff direction.
- The gateway is OpenAI-API compatible, so the `openai` SDK works unchanged —
  only `base_url` differs. Keep the `/api/v2` suffix.
- `seed` is only sent for `gpt-*` models; Claude and Gemini reject it, so
  consistency rests on `temperature = 0`.
- List models your token can use: `cli-genaigateway models list`
